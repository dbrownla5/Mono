# dev-tooling

**Intent:** the Claude Code setup — configuration, skills, agents, and dev
workflow patterns. Getting this clean helps **every future session run better**
(which is part of the frustration we're trying to fix).

**Provisional source repos:** `claude-code-best-practice`, `skills`

**Goal:** pull out the config patterns, skills, and agents that are worth
keeping and standardize them, so the assistant behaves consistently across
projects instead of drifting.

As this bucket is worked, extracted pieces land in:
- `tools/` — reusable skills, agents, hooks, commands
- `content/` — the best-practice docs worth keeping

_Status: not started._
