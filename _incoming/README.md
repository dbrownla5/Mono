# _incoming — raw staging

When a source repo is first cracked open, anything interesting gets dropped here
under `_incoming/<repo-name>/` **before** it's sorted.

This is the messy landing zone on purpose. Nothing here is final. Once a repo's
pieces are reviewed, the keepers move out into the right `buckets/<name>/` and
the staging folder is cleared.

If something is sitting here, it means: _pulled out, not yet sorted._
