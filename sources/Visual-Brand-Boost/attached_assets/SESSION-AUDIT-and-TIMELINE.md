## 5. How to restore an older session's memory (if you need it)

In the Replit workspace:
1. Click the **History** icon (clock symbol, left sidebar).
2. You'll see every checkpoint above as a row, with a "Restore" button.
3. Restoring brings back **both** the code at that moment **and** the agent's memory of what was discussed.
4. Restoring is non-destructive — current state is saved before the rollback.

If a previous chat had your 6-month vision in it, it lives inside one of those `.bin` snapshots. Restoring the checkpoint right before the conversation went sideways will recover that thread.
