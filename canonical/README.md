# canonical/ — The Well Lived Citizen, assembled in one place

This is the thing nobody finished: **one converged view of the company**, pulled
from the newest authoritative sources across all the repos, deduped, with the few
genuinely-open items isolated on one page (`DECISIONS.md`).

## How this was built
- Read across the richest repos: `wlc-build-2026` (the 6/12 "truth layer"),
  `May24` (the live April/May site + audit), `wlc-portal` (the working client
  portal), plus the reseller/shipping tools.
- Where sources disagree, the **newest authoritative** one is used and the older
  one is noted — never silently dropped.

## The rule this honors (Dayna's own doctrine)
From the `wlc-voice-recovery` skill: **"Do not use false finality. If source
material says [LOCKED], treat it as a claim requiring provenance, not automatic
truth."** So nothing here is "TRUTH." It is **current-best**, assembled and
sourced, for Dayna to confirm. She decides; the documents don't.
